# RDEX — Riya Raj Portfolio

> A modern, responsive developer portfolio built with React, TypeScript, and Tailwind CSS.

## 🌐 Overview

**RDEX** is my personal developer portfolio designed to showcase my technical skills, professional experience, projects, education, certifications, and development journey.

The portfolio focuses on a clean developer-oriented interface with interactive sections and a responsive experience across desktop and mobile devices.

## ✨ Features

* 🎯 Professional hero section with developer introduction
* 👩‍💻 About & career overview
* 💼 Experience and internship details
* 🚀 Featured project showcase
* 🛠️ Technical skills and technology stack
* 🎓 Education and certifications
* 🖥️ Interactive developer terminal section
* ⌨️ Command palette navigation
* 📄 Resume preview
* 📬 Contact section
* 📱 Fully responsive design
* ⚡ Fast Vite-powered development and production builds

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd rdex-riya-raj-portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available on the local development server provided by Vite.

### 4. Build for production

```bash
npm run build
```
